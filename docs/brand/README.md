# Brand

- **Mark:** a sprout rising from a coin circle. Single colour, drawn on a 16px grid so it holds up at tray size.
- `mark.svg` is moss (`#346B4F`) for light backgrounds; `mark-dark.svg` is light moss (`#96CCA7`) for dark ones.
- `app-icon.svg` puts the light mark on a dark canvas tile (`#111A17`). The app icon PNGs and `.ico` in `src/Mossmint.Desktop/Assets/` are generated from it; regenerate them after editing.
- **Wordmark:** "Mossmint" in Manrope Bold, −0.01em tracking, sentence case.
- **Tagline:** Make room to grow.
- The mark is licensed MIT with the code. Decorative icons (Lucide, ISC) stay separate from the financial status set.
